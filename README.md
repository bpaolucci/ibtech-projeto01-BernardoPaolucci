# Cartão de Visita Pessoal — Bernardo Paolucci

## Sobre o projeto
Página pessoal desenvolvida como Projeto 01 da trilha Frontend da IbTech 2026.1.
Um cartão de visita na internet com identidade visual temática Batman/Gotham City.

## Tecnologias
- HTML5 semântico
- CSS3 com variáveis, Flexbox e animações
- JavaScript vanilla
- Canvas API

## Funcionalidades
- Tema claro (Mansão Wayne) e escuro (Bat Caverna) com persistência em localStorage
- Roleta de habilidades animada
- Cards de mídia com efeito flip ao passar o mouse
- Menu mobile com drawer lateral
- Animação de entrada das seções com IntersectionObserver
- Easter egg — clique 3 vezes no avatar

## Como rodar
Abrir o arquivo `index.html` no navegador.
